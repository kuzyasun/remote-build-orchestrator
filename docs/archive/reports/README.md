# Archived reports

These files preserve machine-readable compatibility and security evidence used by regression
tests. They are not part of the normal user or developer reading path.

- `matrix.json` records the last explicit AI client and transport verification state.
- `threat-coverage.json` maps security cases to tests or environment gates.
- `evidence/` contains the protocol-harness notes referenced by verified matrix entries.

Update a report only when the corresponding evidence changes. Do not infer client compatibility.
